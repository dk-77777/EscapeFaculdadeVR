# Checklist de desenvolvimento

## Fase 1 - Base VR
- [ ] Projeto criado com VR Template.
- [ ] Cena de teste abre sem erros.
- [ ] XR Origin funciona.
- [ ] Jogador consegue olhar e mover-se.
- [ ] Controles aparecem/respondem.
- [ ] Jogador consegue interagir com um objeto.

## Fase 2 - Graybox
- [ ] Sala inicial.
- [ ] Corredor principal.
- [ ] Laboratorio.
- [ ] Biblioteca/sala de estudos.
- [ ] Sala do professor.
- [ ] Saida principal.
- [ ] Colisores em todas as paredes/chao.

## Fase 3 - Sistemas
- [ ] GameManager.
- [ ] Porta abrindo.
- [ ] Teclado numerico.
- [ ] Puzzle 1 funcionando.
- [ ] Puzzle 2 funcionando.
- [ ] Puzzle 3 funcionando.
- [ ] Puzzle 4 funcionando.
- [ ] Cartao 1.
- [ ] Cartao 2.
- [ ] Cartao 3.
- [ ] Terminal final.
- [ ] Vitoria.
- [ ] Derrota.

## Fase 4 - Professor
- [ ] Modelo temporario ou final.
- [ ] Animacao de caminhada/corrida.
- [ ] Primeira aparicao.
- [ ] Primeiro evento de perseguicao.
- [ ] Evento final.
- [ ] Captura do jogador.

## Fase 5 - Polimento
- [ ] Sons de portas.
- [ ] Sons de botoes.
- [ ] Ambiente da faculdade.
- [ ] Passos/voz do professor.
- [ ] Musica de perseguicao.
- [ ] Luzes de emergencia.
- [ ] Luzes piscando sem exagero.
- [ ] Objetivos na tela.
- [ ] Tela de derrota.
- [ ] Tela final.
- [ ] Creditos.

## Fase 6 - Entrega
- [ ] Teste completo sem usar o Editor para consertar nada no meio.
- [ ] Teste no headset da faculdade.
- [ ] Build final.
- [ ] Copia do projeto em outro computador/drive.
- [ ] Copia do build final.
- [ ] Apresentacao ensaiada.
